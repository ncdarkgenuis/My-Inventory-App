# CoreMetrics: Modern Inventory & Operations Dashboard

**CoreMetrics** is a full-stack web application designed for small business owners and engineering teams to streamline their stock management and client communication. Built with a focus on simplicity, responsiveness, and performance.

## ✨ Features
*   **Inventory Management System**: Add and track products, quantities, and pricing in real-time.
*   **Persistent Storage**: Powered by a relational SQLite database to ensure data is never lost.
*   **Responsive Dashboard**: A modern, mobile-friendly UI that works on laptops, tablets, and smartphones.
*   **Client Lead Generation**: Integrated contact form for seamless communication with stakeholders.
*   **Modern Tech Stack**: Leveraging Python (Flask), SQLite, and a decoupled Frontend (HTML/CSS/JS).

## 🛠️ Tech Stack
*   **Backend**: Python / Flask
*   **Frontend**: HTML5, CSS3, Vanilla JavaScript
*   **Database**: SQLite3
*   **Server**: Gunicorn
